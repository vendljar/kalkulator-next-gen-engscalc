Sezení (nearchivovaná)

hotovoteďčeká
Jen sezení, která nejsou archivovaná; hotové a archivované se skrývají. Fáze (u dávek): kód → testy → mutace → souhrn → integrace → sady → test. Zbývá = odhad koordinace. Kontext = čerpání limitu sezení (nad 60 % žlutě, nad 75 % červeně).
