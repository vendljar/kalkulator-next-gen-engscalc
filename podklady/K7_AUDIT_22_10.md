## Co drží (ověřeno pokusem, není-li uvedeno jinak)

- **Práva exportu controllingu:** export i `?protokol=1` → 403 obchodníkovi a vedoucímu, 401 nepřihlášenému, 200 adminovi (`vyzadujRoli(req,'Administrátor')`, `controlling_export.mjs:41`). Nákupní ceny jdou jen tudy.
- **Navazující dávka:** cizí admin s cizím `export` id → 409; jiný filtr → 409; `po` bez `export` → 400; neplatné id → 400; mapování změněné během exportu → 409. Kurzor řazený podle jména (striktně `>`), rozebraná čtení vždy doběhnou → dávky nic nezdvojí ani nepřeskočí (mimo K7-S8).
- **`/api/pd/stav`:** ven jen `{ok, nastaveno, pdStav:{status,nacteno}}`, žádný token ani hodnota dealu; deal id bere server ze zakázky; POST → 405; obchodník měnící `pdDealId` → 403; prozradí totéž co GET `/api/zakazky?soubor` (otevřený všem přihlášeným).
- **`pdStav` z klienta:** objekt, pole, `{"toString":1}`, `__proto__` → 400, ne 500; platný podvrh `won` → 200, ale neuloží se (dosazuje server z `pd_stav`).
- **`ctrlDny`:** počítá jen server; vložené do těla zakázky se ignoruje. Předvýběr podle zámku i prodeje odpovídá `ctrlHromadnyZakazka` (den v Praze, rezerva ±2 dny).
- **Snímek Z1 u nového zámku:** `{"toString":1}`, `[]`, `0`, `false`, `""` → 409, nic 500. Snímek je v klíči zámku (`src/uloziste.js:584-586`), server porovnává podle uložené verze (`zakazka_kontrola.mjs:390`), neznámé pole krycího listu je zmrazené (`src/zamek.js:384`), DPH volná jen se snímkem a před SoD. Kontakt po SoD volný (Z1-3), zástupci, DIČ, objednatel zmrazení; zákazník z databáze a našeptávač mají kontrolu Z1.
- **Dotisk:** CN přes `zamekNabidkaPohled` (`src/nabidka.js:19`, `src/nabidka_proj.js:592`), SoD `zive`; cena díla SoD ze zmrazeného `vypocetZ` a téže měny/kurzu jako CN; dotisk SoD z `tisky[].sod`.
- **XSS:** v přidaných řádcích žádný nový `insertAdjacentHTML`/`outerHTML`/`eval`; `onclick` jen s konstantami a `escJs`. Stav Pipedrive přes výčet `pdStavNorm` (pokus `<img onerror>'"` ve všech polích → „neznámý“/„nepropojeno“); hlášky exportu přes `ctrlUiZprava` → `esc`, dialogy `dlgEsc`; `sodStavText` přes `textContent`.
- **Nákupní ceny:** nová místa (dlaždice EUR, karta objednaných, `tisky[].sod`, `ctrlDny`, stav PD) nesou jen prodejní ceny nebo data.
- **Výkon:** doplnění `ctrlDny` ≤ 26 čtení na uložení (pokus s 1000 záznamy); dávka exportu omezena počtem, bajty a časem, odpověď > 5 MB → 413.
- **Tajemství a osobní údaje:** `kontrola_udaju.py` čistá (574 souborů); přidané řádky (5124): e-maily jen smyšlené domény, žádné tokeny, klíče, hesla, ID ostrých dealů (testy 4711/4712/9000 a podvržený `fetch`), žádné ceny ostrého ceníku; výjimka telefonu kolegy z povoleného seznamu odebrána. Výjimka: K7-W1.

- **`--kontrola` mutací:** jádro 492/492, server 829/829 (počty sedí s CHANGELOG). Nové testy v kopii všechny kód 0 (např. `test_zmrazeni_kl` 107/0, `test_pd_stav` 63/0 + server 41/0, `test_prava` 932/0); ruční mutanty #505, P1, D5-3 a části #504 chyceny.
